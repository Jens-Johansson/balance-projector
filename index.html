Syntax cheat-sheet
unit: k€ — sets the money unit (default €).
2027 alone on a line — every date below it is in that year, until the next year line.
sep: 12 note — a bare month means mid-month (the 15th).
sep 10: … / 2027 aug 3: … / 2026-12-24: … — explicit days, inline years, ISO all work.
: - .35 * 6 * 12 some costs — the amount is evaluated algebraically (+ - * / ( )); everything after it is the event label.
: 45 # * 1000 * 45 note — use # to say exactly where the amount stops and the description starts.
: [monthly] etc, — use square brackets [...]to make a recurrent amount, eg yearly, 3 months, 10 days
Any line without a colon or without a recognisable date is a free-form comment and becomes a section heading for the entries below it.
